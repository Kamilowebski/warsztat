# TurboFix - One Page Website (React + HTML)

Nowoczesna, responsywna strona wizytówkowa dla warsztatu samochodowego, przygotowana jako projekt do portfolio.

## Demo projektu

Repozytorium: [https://github.com/Kamilowebski/warsztat](https://github.com/Kamilowebski/warsztat)

## Co zawiera strona

- układ `one-page` z nawigacją do sekcji
- sekcje: Hero, Usługi, O nas, Opinie, Kontakt
- responsywny layout (desktop / tablet / mobile)
- formularz kontaktowy z walidacją po stronie React:
  - imię (min. 2 znaki)
  - telefon (9-15 cyfr)
  - e-mail (poprawny format)
  - wiadomość (min. 10 znaków)
- komunikaty błędów i potwierdzenie poprawnego wysłania
- poprawka `sticky menu` (nagłówki nie chowają się po kliknięciu)

## Technologie

- HTML5
- CSS3
- React 18 (CDN)
- Babel Standalone (JSX w przeglądarce)

## Jak uruchomić lokalnie

1. Sklonuj repo:
   ```bash
   git clone https://github.com/Kamilowebski/warsztat.git
   ```
2. Wejdź do folderu projektu.
3. Otwórz plik `index.html` w przeglądarce.

## Struktura projektu

```text
warsztat/
  index.html
  styles.css
  README.md
```
